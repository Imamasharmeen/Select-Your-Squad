


#  🏏 Dream 11 Cricket Team Selector

Build Your Dream Cricket Team
An interactive web application that lets users assemble their ultimate cricket team by selecting players based on available in-game coins. Get real-time feedback with notifications and manage your team strategically!

## ✨ Project Overview
This project provides a dynamic platform for users to create a personalized Dream 11 cricket team by selecting players within a set coin balance. The interface provides a smooth user experience with interactive feedback and state management, allowing users to see their selected players, available coins, and a clear limit on team size.

## 🔧 Technologies Used
React - Core framework for component-based UI.
Tailwind CSS - Rapid, utility-first styling.
React Toastify - For customizable in-app notifications.
## 🌟 Key Features
Real-time Coin Management
Track and manage your available coins while selecting players, with instant feedback if you lack enough coins to add a player.

Player Selection with Notifications
Select up to six players and receive notifications on team status, selection limits, and coin deductions.

Toggle Between Available and Selected Players
Easily switch between the list of available and selected players to optimize your team-building strategy.
